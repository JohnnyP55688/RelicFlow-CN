# 肝武助手 RelicFlow CN

面向 FFXIV 国服的遗物武器流程与进度助手。

## 0.3.0 测试版

- 首页按“战斗肝武、深层迷宫武器、制作采集工具”三类浏览。
- 收录 2.0 至 7.0 的主线肝武、深层迷宫带出武器和制作采集特殊工具。
- 手动勾选并持久保存完成状态。
- 自动显示当前武器线的下一步。
- 全中文界面，命令 `/relicflow` 或 `/肝武助手`。
- 当前版本不会移动、战斗、传送、排本或消费物品。
- 通过 Tsukimichi（月道）的只读 IPC 获取角色任务状态，但结果直接显示在 RelicFlow，不跳转月道界面。
- 灰机 Wiki 仅作为攻略参考链接；插件核心进度不会依赖网页在线可用性。

### 0.2.0 更新

- 新增玩家任务状态读取桥接。
- 下一任务、当前步骤和阻塞原因直接显示在 RelicFlow 中。
- 不提供跳转月道界面的按钮。

### 0.3.0 更新

- 新增三类顶层目录，避免把主线肝武、深层迷宫武器和制作采集工具混在一起。
- 新增曼德维尔、幻境、角尊／闪熠、天之、正统／高尚、光耀／圣礼等路线。
- 新增华光、赐福、天钢、辉煌、莫雯卓越和宇宙工具路线。
- 每个阶段标明对应 FF14 灰机 Wiki 资料页名称；当前仍为离线清单，不依赖网页可用性。

## 可选依赖与来源

- Tsukimichi（月道）：MIT 许可，提供只读任务状态 IPC。RelicFlow 不复制其任务数据库。
- FF14 灰机 Wiki：通过标准 MediaWiki API 或页面链接作为中文攻略参考，不作为角色状态来源。

这是第一阶段的免费核心。后续将逐项加入天火文书详细目标、材料库存读取和现有插件状态检测；只有经过游戏内验证的功能才会标记为可用。

## 开源与后续模块

- 本仓库是免费的开源核心，使用 MIT 许可证。
- 免费核心包含遗物资料、进度读取、下一步提示和安全的插件联动界面。
- 未来若开发订阅功能，将作为独立闭源模块维护，不把第三方开源代码混入闭源部分。
- 自动化功能必须由用户明确启动，并与其他自动控制插件互斥。
